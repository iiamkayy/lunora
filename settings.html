How login works

Your lunora profile is your messenger account — one username and password for both. Create it on the login screen the first time; "use another account" lets friends sign into their own profiles on this device.

Browser Engine

lunora's built-in browser routes pages through Scramjet v2 (default), Ultraviolet, or loads them Directly. Proxied engines need a backend — self-host with node server.js for everything to work out of the box.

Scramjet checking… default

v2.0.67-alpha — the new interception-based engine from Mercury Workshop. Most advanced rewriting; alpha quality on a few sites.

Ultraviolet checking…

v3.2.7 — the classic, battle-tested engine. Great compatibility, epoxy transport over wisp.

Direct always ready

No proxy at all — pages load as raw frames. Works for sites that allow embedding (many game hosts do); big sites like Google will refuse to frame.

Backend endpoints

Wisp serverused by the epoxy transport (scramjet + ultraviolet)
Bare serverultraviolet fallback endpoint

Defaults are automatic: when you run node server.js, wisp and bare are served by the same server you're on.
